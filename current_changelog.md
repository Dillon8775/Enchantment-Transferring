# Version 1.1

## Now requires [DillonLib](https://modrinth.com/mod/dillon-lib) in order to run.

## Changes
- New texture for enchantment transferrer block.
- New interface for the enchantment transferrer.
    - Transferring enchantments has been optimized.
    - You can now transfer enchantments directly to empty books.
    - Add a diamond to negate durability damage from the tool.
    - Purely based off of the [Speedrunner Mod](https://modrinth.com/mod/speedrunner-mod).
- The enchantment transferrer is now considered a "block entity".
- Fixed bug where using enchantment transferrer sometimes opens the crafting table GUI.
- Now requires Fabric Loader 0.19.3 or greater to load.
- Backend optimizations.
